Namespace StellarDotnetSdk.LiquidityPool

Classes

LiquidityPool

Represents a Stellar liquidity pool, which holds reserves of two assets and allows decentralized trading based on an automated market maker (AMM) algorithm.

LiquidityPoolConstantProductParameters

Represents the parameters for a constant-product liquidity pool (x * y = k). The two assets must be in lexicographic order (Asset A < Asset B).

LiquidityPoolId

Represents the unique identifier of a Stellar liquidity pool, derived from the SHA-256 hash of the pool's parameters (type, assets, and fee).

LiquidityPoolParameters

Base class for liquidity pool parameters on the Stellar network. Defines the pool type, assets, and fee structure for an automated market maker (AMM) pool.
