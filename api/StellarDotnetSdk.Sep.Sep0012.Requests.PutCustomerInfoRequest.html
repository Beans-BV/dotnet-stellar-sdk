Remarks

Fields are written in this order, a later source overriding an earlier one with the same name: identification parameters, KycFields, CustomFields, VerificationFields, FileReferences; then the binary parts from KycFields followed by CustomFiles. A name used by both a text field and a binary field (for example CustomFields["photo_id_front"] with PhotoIdFront) is rejected with an ArgumentException before sending.
