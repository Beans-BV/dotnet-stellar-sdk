Table of Contents

Namespace StellarDotnetSdk

Classes

Amount

Utility class for converting between Stellar amount representations. Stellar stores amounts as 64-bit integers with 7 decimal places of precision (1 XLM = 10,000,000 stroops).

Base32Encoding

Provides RFC 4648 Base32 encoding and decoding methods. Used internally by StrKey for encoding and decoding Stellar keys and identifiers.

Base32Encoding.Base32EncodingOptions

Options for controlling Base32 encoding behavior.

ClaimAtom

Represents a single trade that was executed during a path payment or offer operation on the Stellar network. Each claim atom contains the assets and amounts exchanged.

ClaimAtomLiquidityPool

Represents a claim atom from a liquidity pool trade on the Stellar network. Contains the liquidity pool ID and the assets and amounts exchanged.

ClaimAtomOrderBook

Represents a claim atom from an order book trade on the Stellar decentralized exchange. Contains the seller, offer ID, and the assets and amounts exchanged.

ClaimAtomV0

Represents a V0 claim atom from a trade on the Stellar network. This is the original format that identifies the seller by their Ed25519 public key rather than a full account ID.

ClaimableBalanceIdUtils

Utility methods for converting between different representations of Stellar claimable balance IDs (base32 B..., hex 0000..., and XDR).

HashCode

Provides fluent hash code generation utilities using the FNV-style chained hashing pattern.

Network

Represents a Stellar network identified by its unique passphrase. The passphrase is hashed to produce the network ID, which is used to distinguish transactions on different networks (e.g., public mainnet vs. testnet).

Price

Represents a price as a ratio of two 32-bit integers, used for building Stellar transactions.

Server

Provides access to the Stellar Horizon API server. Offers request builders for querying accounts, assets, transactions, and other Stellar resources, as well as methods for submitting transactions.

SignedPayloadSigner

Data model for the https://github.com/stellar/stellar-protocol/blob/master/core/cap-0040.md#xdr-changes signed payload signer

Signer

Represents an account signer with a signing key and associated weight. Signers are used to authorize transactions for Stellar accounts, where the weight contributes toward meeting the required signing thresholds.

SignerUtil

Signer is a helper class that creates StellarDotnetSdk.Xdr.SignerKey objects.

StrKey

Provides methods for encoding and decoding Stellar keys using StrKey format (RFC 4648 base32 with a version byte prefix and CRC16-XModem checksum). This format is used for all human-readable Stellar identifiers including account IDs (G...), secret seeds (S...), contract IDs (C...), and muxed accounts (M...).

Util

General-purpose utility methods for byte/hex conversion, hashing, and array manipulation used throughout the Stellar SDK.

WebAuthentication

Implement SEP-10: Stellar Web Authentication. https://github.com/stellar/stellar-protocol/blob/master/ecosystem/sep-0010.md

Enums

StrKey.VersionByte

Specifies the type of Stellar key, encoded as the first byte of a StrKey-encoded string. Each version byte determines the prefix character of the encoded key (e.g., 'G' for accounts, 'S' for seeds, 'C' for contracts).
