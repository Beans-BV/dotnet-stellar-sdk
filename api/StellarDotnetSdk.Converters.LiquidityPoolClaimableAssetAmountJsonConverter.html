Remarks

Duplicate JSON property names are always rejected with a JsonException, matched case-insensitively. This is intentional hardening for financial fields and does not honor the JsonSerializerOptions passed to Read(ref Utf8JsonReader, Type, JsonSerializerOptions) — neither AllowDuplicateProperties nor PropertyNameCaseInsensitive changes it.
