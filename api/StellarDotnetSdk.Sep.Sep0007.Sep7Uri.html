A parsed and validated SEP-7 request (web+stellar:tx?... or web+stellar:pay?...). Instances come from ParseUri(string) or TryParseUri(string?, out Sep7Uri?), so every parameter has already passed the checks described there. Parameter values are URL-decoded.
