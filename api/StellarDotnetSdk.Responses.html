Classes

AccountDataResponse

Represents a single data entry attached to an account. Account data entries are key-value pairs that can store arbitrary data on an account.

AccountResponse

Represents an account on the Stellar network. Contains account balances, signers, thresholds, and other account state.

AccountResponse.Signer

Represents a signer authorized to sign transactions for an account.

AccountResponseLinks

Links to related resources for an account.

AssetResponse

Represents asset information from the Horizon API. Contains statistics about the asset including holder counts, balances, and authorization flags.

AssetResponse.AssetAccounts

Statistics about accounts holding the asset, categorized by authorization status.

AssetResponse.AssetBalances

Total balances of the asset, categorized by authorization status.

AssetResponse.AssetResponseLinks

Links associated with the asset response.

Balance

Represents an account's balance in a specific asset or liquidity pool shares. An account can hold multiple balances, one for each trusted asset.

ClaimableBalanceResponse

Represents a claimable balance on the Stellar network. A claimable balance is an amount of an asset that has been transferred from one account to be claimed by one or more potential claimants based on specified conditions.

ClaimableBalanceResponse.ClaimableBalanceFlags

Represents claimable balance flags.

ClaimableBalanceResponse.ClaimableBalanceResponseLinks

Links to related resources for a claimable balance.

Claimant

Represents a claimant in Horizon API responses.

FeeStatsResponse

Represents fee statistics for the Stellar network. Provides information about transaction fees across recent ledgers to help with fee estimation.

FeeStatsResponse.FeeStatsResponseData

Contains statistical data about fees including minimum, maximum, mode, and percentiles.

Flags

Represents account authorization flags that control how an issuing account manages trust and authorization for its issued assets.

FriendBotResponse

Represents the response from the Friendbot service on testnet. Friendbot is a service that funds accounts with test XLM on the Stellar testnet.

FriendBotResponse.FriendBotResponseLinks

Links associated with the Friendbot response.

HealthResponse

Represents the health check response from a Horizon server. Provides information about the operational status of the Horizon instance.

LedgerBounds

The ledger range for which this transaction is valid, as unsigned 32-bit integers.

LedgerResponse

Represents a ledger from the Stellar network. A ledger is equivalent to a block in other blockchain systems and contains all transactions that were applied during that consensus round.

LedgerResponse.LedgerResponseLinks

Links to related resources for a ledger.

Link

Represents a HAL hypermedia link. Links provide navigation to related resources in the Horizon API.

Link<TResponse>

Represents a typed HAL hypermedia link that can be followed to retrieve a resource. Supports both direct links and URI templates.

LiquidityPoolResponse

Represents a liquidity pool on the Stellar network. Liquidity pools enable automated market making (AMM) for trading asset pairs.

LiquidityPoolResponse.LiquidityPoolResponseLinks

Links to related resources for a liquidity pool.

OfferResponse

Represents an offer on the Stellar decentralized exchange. An offer is a bid or ask to exchange one asset for another at a specified price.

OfferResponse.OfferResponseLinks

Links to related resources for an offer.

OrderBookResponse

Represents an order book for a trading pair on the Stellar decentralized exchange. Contains both buy orders (bids) and sell orders (asks).

OrderBookResponse.Row

Represents a single row in the order book (either an ask or a bid).

Page<T>

Represents a paginated page of objects from the Horizon API. Used to navigate through large result sets using cursor-based pagination.

Page<T>.EmbeddedRecords

Container for embedded records in HAL JSON format.

Page<T>.PageLinks<T>

Navigation links for paginated responses.

PathResponse

Represents a payment path found by the path finding algorithm. A path is a sequence of assets that can be used to convert from a source asset to a destination asset through the Stellar decentralized exchange.

Price

Represents a price ratio in Horizon API responses.

Reserve

Represents a reserve in a liquidity pool, containing an asset and its amount.

Response

Abstract base class for all Horizon API responses. Provides common functionality for handling rate limit headers.

RootResponse

Represents the root endpoint response from a Horizon server. Contains version and network information about the Horizon instance.

RootResponseLinks

Contains the navigational links returned by the Horizon root endpoint, providing URIs for all available API resources.

SubmitTransactionAsyncResponse

Represents the response from an asynchronous transaction submission. Async submission is faster but requires polling for the final status.

SubmitTransactionResponse

Represents the response from a synchronous transaction submission to Horizon. Contains the result of the transaction execution including success/failure status.

SubmitTransactionResponse.Extras

Additional information returned by the server, typically on failure.

SubmitTransactionResponse.Extras.ResultCodes

Contains result codes for this transaction. See Possible values

TemplatedLink<TResponse>

Represents a templated HAL hypermedia link that requires variable substitution. URI templates follow RFC 6570.

Thresholds

Operations have varying levels of access. This field specifies thresholds for different access levels, as well as the weight of the master key.

TimeBounds

The time range for which this transaction is valid, with bounds as unsigned 64-bit UNIX timestamps.

TradeAggregationResponse

Represents aggregated trade data for a specific time period. Trade aggregations provide OHLC (Open, High, Low, Close) candlestick data for trading pairs on the Stellar DEX.

TradeResponse

Represents a trade that was executed on the Stellar decentralized exchange. A trade occurs when offers are matched or when interacting with a liquidity pool.

TradeResponse.TradeResponseLinks

Links to related resources for a trade.

TransactionResponse

Represents a transaction on the Stellar network. Contains transaction metadata, results, and links to related resources.

TransactionResponse.FeeBumpTransaction

Represents the fee bump transaction wrapper for a fee-bumped transaction.

TransactionResponse.InnerTransaction

Represents the inner transaction within a fee bump transaction.

TransactionResponseLinks

Links to related resources for a transaction.

TransactionResponsePreconditions

A set of transaction preconditions affecting its validity.
