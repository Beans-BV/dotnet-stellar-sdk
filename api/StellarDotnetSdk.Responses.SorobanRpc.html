Events

Represents the collection of events returned from a Soroban transaction simulation or execution, including diagnostic events, transaction events, and contract events in XDR format.

GetEventsResponse

Holds the details of the response of getEvents().

GetEventsResponse.EventInfo

Represents a single event emitted by a Soroban smart contract, including its metadata and payload.

GetFeeStatsResponse

Statistics for charged inclusion fees. The inclusion fee statistics are calculated from the inclusion fees that were paid for the transactions to be included onto the ledger. For Soroban transactions and Stellar transactions, they each have their own inclusion fees and own surge pricing. Inclusion fees are used to prevent spam and prioritize transactions during network traffic surge.

GetHealthResponse

Represents the response from the Soroban RPC getHealth method. Contains the health status, ledger information, and retention window of the Soroban RPC server.

GetLatestLedgerResponse

Represents the response from the Soroban RPC getLatestLedger method. Contains the hash, sequence number, protocol version, close time, and encoded header and metadata of the most recent ledger.

GetLedgerEntriesResponse

Represents the response from the Soroban RPC getLedgerEntries method. Contains the requested ledger entries and the latest ledger sequence number. A null element in the entries array fails deserialization with JsonException.

GetLedgerEntriesResponse.LedgerEntryResult

Represents a single entry fetched from Soroban server by method getLedgerEntries().

GetLedgersResponse

Holds the details of the response of getLedgers().

GetNetworkResponse

General information about the currently configured network. This response will contain all the information needed to successfully submit transactions to the network this node serves. See https://developers.stellar.org/docs/data/apis/rpc/api-reference/methods/getNetwork

GetTransactionResponse

Represents the response from the Soroban RPC getTransaction method. Extends TransactionInfo with additional ledger context about when the request was handled.

GetTransactionsResponse

Represents the response from the Soroban RPC getTransactions method. Contains a list of transactions and ledger context information.

GetVersionInfoResponse

Version information about the RPC and Captive core. RPC manages its own, pared-down version of Stellar Core optimized for its own subset of needs. we'll refer to this as a "Captive Core" instance.

InclusionFee

Represents inclusion fee distribution statistics, including percentile breakdowns, for transactions over a range of recent ledgers.

LedgerInfo

SendTransactionResponse

Transaction status and network state. The result will include if the transaction was successfully enqueued, and information about the current ledger.

SimulateTransactionResponse

The response will include the anticipated affects the given transaction will have on the network. Additionally, information needed to build, sign, and actually submit the transaction will be provided.

See https://developers.stellar.org/docs/data/apis/rpc/api-reference/methods/simulateTransaction/

SimulateTransactionResponse.LedgerEntryChange

Represents a change to a ledger entry that would result from executing the simulated transaction, including the entry's state before and after the change.

SimulateTransactionResponse.RestorePreamble

It can only present on successful simulation (i.e. no error) of InvokeHostFunction operations. If present, it indicates the simulation detected expired ledger entries which requires restoring with the submission of a RestoreFootprint operation before submitting the InvokeHostFunction operation. The MinResourceFee and SorobanTransactionData fields should be used to construct the transaction containing the RestoreFootprint operation.

SimulateTransactionResponse.SimulateInvokeHostFunctionResult

Used as a part of simulate transaction. See https://developers.stellar.org/docs/data/apis/rpc/api-reference/methods/simulateTransaction

SimulateTransactionResponse.SimulateTransactionCost

Information about the fees expected, instructions used, etc.

SorobanRpcErrorResponse

Represents the error member of a JSON-RPC 2.0 response (JSON-RPC 2.0 §5.1) returned by the Stellar RPC server. A response carrying this member has no result member.

SorobanRpcResponse<T>

Represents a generic JSON-RPC response from the Soroban RPC server, wrapping the typed result along with the request ID and JSON-RPC version.
