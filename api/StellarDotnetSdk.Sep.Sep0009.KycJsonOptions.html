JSON serializer options for SEP-0009 KYC field types. Date fields use ISO 8601 date-only format (yyyy-MM-dd) on every target framework: via DateOnly converters on net8.0/net10.0 and via IsoDateStringJsonConverter property annotations on netstandard2.1, so invalid date strings are rejected on all targets.

Remarks

These options use CamelCase (emitting e.g. birthDate), so they are intended for internal/persistence serialization — NOT for the SEP-0009 wire format, which uses snake_case field keys (e.g. birth_date). SEP-0009 submission/parsing goes through the typed field models and their *_FieldKey constants, not these options. Deserializing a raw SEP-0009 server payload with Default would silently skip every snake_case field.
