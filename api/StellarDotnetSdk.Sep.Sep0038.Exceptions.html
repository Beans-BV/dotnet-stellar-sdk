Namespace StellarDotnetSdk.Sep.Sep0038.Exceptions

Classes

BadRequestException

The anchor's SEP-38 quote server answered 400 Bad Request: the request was invalid in some way, for example an unsupported asset or a missing required parameter.

NoAnchorQuoteServerFoundException

The domain's stellar.toml does not declare a usable ANCHOR_QUOTE_SERVER: either the key is missing, so the anchor does not advertise SEP-38 support, or its value is not an address QuoteService accepts (DeclaredAddress holds it, and the message says why).

PermissionDeniedException

The anchor's SEP-38 quote server answered 403 Permission Denied: no Authorization header was provided or its JWT was not accepted, or the anchor denied access (for example to an account that is not KYC'ed).

QuoteServerException

Base type of the errors QuoteService raises for a response from an anchor's SEP-38 quote server, or for a stellar.toml that declares no usable one. Catch this to handle all of them.

QuoteServerNotFoundException

The anchor's SEP-38 quote server answered 404 Not Found: the resource does not exist. For GET /quote/:id, no quote with that id is visible to the authenticated account; some anchors (the Anchor Platform among them) also answer 404 to GET /price or GET /prices for an asset they do not list, which the specification does not define.

UnexpectedResponseException

The anchor's SEP-38 quote server sent a response the client cannot use: a status code other than 400, 403 or 404 outside the 2xx range, a body larger than the size limit, or a success body that is not a valid response — malformed JSON, a duplicated property, a missing required field, or an amount that cannot be represented exactly.
