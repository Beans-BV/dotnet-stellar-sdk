Remarks

The IReadOnlyList<T> counterpart of NonNullElementArrayJsonConverter<T>, for the same reason: RespectNullableAnnotations constrains the list reference, never its contents, so [null] would otherwise yield a list holding null that the compiler then lets a caller dereference without a check.

Attach it with a property-level JsonConverterAttribute naming the closed type (for example NonNullElementListJsonConverter<DeliveryMethod>). It is public so that a consumer's source-generated JsonSerializerContext can instantiate it.

Elements are read and written one at a time, delegating to JsonSerializer for T alone. That is what a source-generated context supports: it carries metadata for the element type the property exposes, but not for T[] or IEnumerable<T>, which a whole-collection delegation would need. It also means the converter needs no guard against a registration on Converters, unlike NonNullElementArrayJsonConverter<T>: a delegated call for T never resolves back to a converter for IReadOnlyList<T>. Registered globally, it only applies the null-element check to every IReadOnlyList<T> of that element type.
