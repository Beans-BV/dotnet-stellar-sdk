Parameters

ownerContractId string

The contract (C...) that was expected to hold the tag entry. The SDK always passes one; it may be null only when the exception is constructed elsewhere.

tag byte[]

The raw tag bytes that were looked up. They are copied. The SDK always passes them; they may be null only when the exception is constructed elsewhere.

isArchived bool

true when the entry exists but has been archived; false when it does not exist.
