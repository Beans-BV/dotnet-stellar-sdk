Represents a CAP-85 external executable reference (CONTRACT_EXECUTABLE_EXTERNAL_REF). Instead of carrying its own Wasm hash, the contract follows the Wasm hash that ExecutableOwner stores in a persistent contract data entry keyed by SCExecutableTag(Tag), so the owner can upgrade every contract that references the tag at once.

Remarks

The owner can change the referenced Wasm at any time, and so has full control over every contract that follows the reference. Only reference an owner you trust as much as the contract's own admin.

Use GetExternalRefWasmHash(ContractExecutableExternalRef) to resolve the reference to the Wasm hash it currently names.

Parameters

executableOwner ScAddress

The contract that owns the executable. Only a contract can hold the tag entry, so any other address type is unresolvable; it is accepted here so that any reference read from the network can be represented.

tag byte[]

The owner-scoped tag naming the executable. It need not be valid UTF-8. The bytes are copied, so changing the array afterwards does not change this reference.
