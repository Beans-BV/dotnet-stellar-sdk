ChoicesJsonConverter

Reads a field's choices array. SEP-0012 types it only as "an array of valid values", and a field of type number may list numbers, so a number element is kept as its JSON text ([1, 2.5] reads as "1", "2.5"). A null, boolean, object or array element fails the parse.

GetCustomerInfoField

A piece of information the anchor has not yet received for a customer, as listed under fields in the GET /customer response. The dictionary key it is stored under is the field name, normally a SEP-0009 field such as first_name or photo_id_front.

GetCustomerInfoProvidedField

A piece of information the anchor has already received for a customer, as listed under provided_fields in the GET /customer response. Carries the same description as GetCustomerInfoField plus the validation state of the submitted value.

GetCustomerInfoResponse

Status of a customer's KYC process and the fields the anchor still needs or has received. Returned by GET /customer and by the deprecated PUT /customer/verification, and posted by the anchor to the URL registered with PUT /customer/callback (parse that payload with FromJson(string)).

OptionalFlagJsonConverter

Reads a field's optional flag. SEP-0012 defines an absent flag as false, and an explicit null reads the same way, since anchors whose serializers write out null properties send it for "not set". Any other non-boolean value fails the parse.

ProvidedFieldStatusJsonConverter

Wire-literal converter for ProvidedFieldStatus.

PutCustomerInfoResponse

Response of PUT /customer: the identifier of the created or updated customer.

Enums

CustomerStatus

Status of a customer's KYC process, as returned in the status field of GET /customer, of PUT /customer/verification and of the callback payload. Wire values are the exact literals SEP-0012 defines; any other value is rejected when the response is parsed.

FieldType

Data type of a KYC field value, as returned in the type property of GetCustomerInfoField and GetCustomerInfoProvidedField. Wire values are the exact lowercase literals SEP-0012 defines; any other value is rejected when the response is parsed.

ProvidedFieldStatus

Status of a single field the anchor has already received, as returned in Status. Wire values are the exact literals SEP-0012 defines; any other value is rejected when the response is parsed.
