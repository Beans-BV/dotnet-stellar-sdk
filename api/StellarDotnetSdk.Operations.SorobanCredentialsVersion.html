Selects which address-credential variant a signing operation produces.

public enum SorobanCredentialsVersion

Fields

Preserve = 0

Keep the entry's existing credential variant (V1 stays V1, V2 stays V2). The default for signing helpers. Safe for networks not yet on Protocol 27 when the input entry is itself V1.

V1 = 1

Legacy SOROBAN_CREDENTIALS_ADDRESS (CAP-0046). Force this when targeting a network not yet on Protocol 27, or a verifier that cannot check the address-bound signature. Forcing it on a V2 entry downgrades it to a legacy credential, whose signature is not bound to the credential address.

V2 = 2

Protocol 27 address-bound SOROBAN_CREDENTIALS_ADDRESS_V2 (CAP-0071-02); rejected by pre-Protocol-27 networks. Pass it to upgrade a legacy entry at signing time.
