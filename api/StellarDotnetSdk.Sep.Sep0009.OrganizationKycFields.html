Remarks

This record contains byte[] properties for file attachments (e.g., PhotoIncorporationDoc, PhotoProofAddress). Note that record equality for byte[] properties compares by reference, not by content. Two instances with identical file content but different array references will not be considered equal. This is standard C# behavior for array equality.

If content-based equality is required for file attachments, consider overriding Equals and GetHashCode, or use ImmutableArray<byte> instead of byte[].
