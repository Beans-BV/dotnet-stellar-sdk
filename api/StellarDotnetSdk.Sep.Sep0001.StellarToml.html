Parses and provides access to stellar.toml files as defined in SEP-0001. The stellar.toml file is a standardized configuration file that organizations publish at https://DOMAIN/.well-known/stellar.toml to provide information about their Stellar integration, including service endpoints, validators, currencies, and organizational details. See SEP-0001

HttpClient Usage: For production code, it is strongly recommended to pass a shared HttpClient instance to the static methods (FromDomainAsync and CurrencyFromUrlAsync, each with an overload that also takes resilience options). If no HttpClient is provided, a new instance will be created and disposed for each call, which is inefficient and can lead to socket exhaustion under load. Create and reuse a single HttpClient instance (or use IHttpClientFactory) for multiple calls to these methods.
