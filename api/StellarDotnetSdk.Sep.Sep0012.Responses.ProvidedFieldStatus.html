Status of a single field the anchor has already received, as returned in Status. Wire values are the exact literals SEP-0012 defines; any other value is rejected when the response is parsed.

[JsonConverter(typeof(ProvidedFieldStatusJsonConverter))]
public enum ProvidedFieldStatus

Fields

Accepted = 1

ACCEPTED: the field has been validated.

Processing = 2

PROCESSING: the field is being validated; poll GET /customer later for the outcome.

Rejected = 3

REJECTED: the field did not pass validation. Error describes why. If the value may be resubmitted the customer status is NEEDS_INFO, otherwise REJECTED.

VerificationRequired = 4

VERIFICATION_REQUIRED: the field must be verified, for example with a confirmation code sent to the customer. Submit it through VerificationFields.

Remarks

Members are numbered from 1, so default(ProvidedFieldStatus) is not a defined value and never reads as a real one. The type-level converter (also registered on DefaultOptions) serializes the exact wire literal and rejects any other value, including a bare ordinal, when the enum is (de)serialized on its own — as a value or as a dictionary key — unless the caller's own options register an enum converter that claims it first (an options converter outranks a type-level attribute). The SEP-0012 response properties are pinned with property-level converters, which hold regardless. Serializing an object whose ProvidedFieldStatus property was left at default fails with a JsonException.
