CallbackResponseBody

The body the callback URL answered with (at most 512 KiB); null for a Horizon submission. SEP-7 defines no format for it, so it is returned as-is, decoded by its byte order mark if it starts with one (UTF-8 or UTF-16, the mark dropped), else with the charset its Content-Type declares if .NET supports it, else as UTF-8. Without CodePagesEncodingProvider registered, .NET supports only the UTF encodings, US-ASCII and ISO-8859-1 (true Latin-1, not windows-1252 as browsers read it); undecodable bytes become U+FFFD.

IsSuccess

For a callback, whether it answered with a 2xx status: SEP-7 defines nothing about the callback's reply, so that is all the SDK can tell (a callback may still report a problem in a 2xx body, in CallbackResponseBody). For Horizon, IsSuccess; false as well when Horizon returned no response. Neither a callback's non-2xx answer nor a transaction Horizon rejects is thrown, so check this before telling the user the request is done.
