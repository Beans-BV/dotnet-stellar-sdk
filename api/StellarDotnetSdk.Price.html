Remarks

This class is used when constructing operations that require a price (e.g., manage offer, liquidity pool deposit). It uses int (32-bit) for numerator and denominator as required by the Stellar XDR protocol specification.

For deserializing Horizon API responses, use Price instead, which uses long to handle values that may exceed the 32-bit range.
