Remarks

This converter handles 27 operation types (type_i: 0-26): 0 = CreateAccount 1 = Payment 2 = PathPaymentStrictReceive etc. Performance: Parses JSON once into JsonDocument, then deserializes from JsonElement to avoid double-parsing overhead. Dispatches via an O(1) dictionary lookup over the immutable discriminator set: a read-optimized FrozenDictionary on .NET 8 and later, a Dictionary on netstandard2.1.
