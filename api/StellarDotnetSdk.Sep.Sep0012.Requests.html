Namespace StellarDotnetSdk.Sep.Sep0012.Requests

Classes

DeleteCustomerRequest

Request for DELETE /customer/[account]: delete all personal information the anchor stores about a customer. The request must be authenticated as the owner of Account.

GetCustomerFilesRequest

Request for GET /customer/files: fetch metadata of files uploaded with POST /customer/files. SEP-0012 requires one of FileId or CustomerId.

GetCustomerInfoRequest

Request for GET /customer: fetch the fields the anchor needs to register a customer, or check the KYC status of a customer that may already be registered.

PostCustomerFileRequest

Request for POST /customer/files: upload a binary file on its own, so that PUT /customer can reference it by file_id (see FileReferences) — useful when the rest of the customer data is sent in a form that cannot carry files.

PutCustomerCallbackRequest

Request for PUT /customer/callback: register a URL the anchor POSTs to whenever the customer's status changes, replacing any previously registered URL. The anchor stops once the status becomes ACCEPTED or REJECTED.

PutCustomerInfoRequest

Request for PUT /customer: idempotently upload customer information to the anchor. Sent as multipart/form-data, with every text field before any binary field as SEP-0012 requires.

PutCustomerVerificationRequest

Request for the deprecated PUT /customer/verification endpoint. SEP-0012 v1.12.0 replaced it with VerificationFields on PUT /customer; use this only with anchors that still require the old endpoint.
