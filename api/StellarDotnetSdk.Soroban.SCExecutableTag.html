Represents a CAP-85 executable tag (SCV_EXECUTABLE_TAG): the owner-scoped name of an executable. Used as the key of a persistent contract data entry on the owner contract, it names the entry that holds the Wasm hash a ContractExecutableExternalRef currently resolves to.

Remarks

A tag is an unbounded byte string and need not be valid UTF-8. The ledger key of the entry is built from the exact bytes, so InnerValue is the source of truth; use TryGetUtf8String(out string?) to read it as text.
