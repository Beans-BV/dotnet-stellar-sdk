Base exception for SEP-0012 KYC API errors. Thrown as-is for any non-success HTTP status that has no more specific subclass (typically 400 Bad Request, 429 or a 5xx), for a response that arrived from a different origin after a redirect (its StatusCode is that response's status, possibly a success), and when the anchor's KYC server cannot be discovered from its stellar.toml.

Remarks

SEP-0012 error responses carry a human-readable description under the error key; it is exposed through ErrorMessage verbatim. Message quotes a clamped copy of it in which control, format, line-separator and paragraph-separator characters are replaced with spaces, because the text is server-supplied and exception messages routinely end up in logs.

RetryAfterDelay

Gets the delay the server asked the client to wait before retrying, from the Retry-After header of a response such as 429 Too Many Requests or 503 Service Unavailable, or null when the response carried none. Set only on a plain KycServiceException; the more specific subclasses are not raised for those statuses. Named like TooManyRequestsException.RetryAfterDelay; there, RetryAfter is the same value in whole seconds.
