Request to query the anchor's fee schedule for deposit or withdrawal operations. This request allows clients to query the exact fee that would be charged for a specific deposit or withdrawal operation. This endpoint is optional for anchors that can fully express their fee structure in the /info response using fee_fixed, fee_percent, and fee_minimum fields. Authentication: Required if feeEndpointInfo.authenticationRequired is true in the /info response. Provide a SEP-10 JWT token in the Jwt property.
