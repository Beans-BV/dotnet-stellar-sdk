Data type of a KYC field value, as returned in the type property of GetCustomerInfoField and GetCustomerInfoProvidedField. Wire values are the exact lowercase literals SEP-0012 defines; any other value is rejected when the response is parsed.

[JsonConverter(typeof(FieldTypeJsonConverter))]
public enum FieldType

Fields

Binary = 2

binary: binary data such as a photo or document. Submit it as a file through PutCustomerInfoRequest (sent as multipart/form-data after all text fields) or upload it with POST /customer/files and reference the returned file_id.

Date = 4

date: a date value (ISO 8601).

Number = 3

number: a numeric value.

String = 1

string: a text value.

Remarks

Members are numbered from 1, so default(FieldType) is not a defined value and never reads as a real one. The type-level converter (also registered on DefaultOptions) serializes the exact wire literal and rejects any other value, including a bare ordinal, when the enum is (de)serialized on its own — as a value or as a dictionary key — unless the caller's own options register an enum converter that claims it first (an options converter outranks a type-level attribute). The SEP-0012 response properties are pinned with property-level converters, which hold regardless. Serializing an object whose FieldType property was left at default fails with a JsonException.
