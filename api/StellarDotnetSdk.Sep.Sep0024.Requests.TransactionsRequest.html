Request to query transaction history for deposits and withdrawals. This endpoint allows clients to fetch the status and history of transactions with the anchor. It returns transactions associated with the account encoded in the authenticated SEP-10 JWT token. Authentication: Always required. Must provide a SEP-10 JWT token.
