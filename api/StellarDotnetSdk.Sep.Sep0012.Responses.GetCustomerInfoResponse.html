Gets the fields the anchor has not yet received for the customer and requested type, keyed by field name. SEP-0012 requires it for NeedsInfo and allows it with any status. The SDK does not enforce that requirement, so the status stays readable when an anchor omits the fields: expect null here even for NeedsInfo. A null entry fails the parse on every deserialization path.
