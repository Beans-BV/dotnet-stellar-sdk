Response from deposit or withdraw endpoints containing interactive flow details. This response provides the URL for the interactive web interface where the user completes KYC, provides additional details, and receives instructions. The URL should be displayed in a popup window or webview. The client should poll the /transaction endpoint using the provided ID to monitor status changes.
