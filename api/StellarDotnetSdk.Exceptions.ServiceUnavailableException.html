Parameters

retryAfter object

The value of the Retry-After header from the HTTP response. Can be an int/long (delay-seconds), a string in delay-seconds or HTTP-date (RFC 1123, RFC 850, asctime, or ISO 8601) form, or a typed TimeSpan, DateTime, DateTimeOffset, or RetryConditionHeaderValue; any other object is parsed from its ToString() form. Non-positive or unparseable values leave both properties null.

RetryAfterDelay

The Retry-After value parsed as a TimeSpan, or null if absent or unparseable. Supports both the delay-seconds and HTTP-date forms (RFC 7231 §7.1.3) and preserves the full value, whereas RetryAfter exposes whole seconds only. Parsed once when the exception is created; for the HTTP-date form this is the delay that remained at that moment.
