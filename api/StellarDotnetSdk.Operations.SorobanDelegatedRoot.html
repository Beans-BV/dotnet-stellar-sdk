The root address credential of a delegated authorization (SorobanAddressCredentialsWithDelegates): its bare address/nonce/expiration/signature fields. On the wire CAP-0071-01 embeds these as a discriminant-free SorobanAddressCredentials struct, and the signature is computed over the address-bound (delegated) payload. Unlike SorobanAddressCredentials this type is deliberately NOT a serializable SorobanCredentials: serializing the root on its own would emit a standalone credential the network rejects, so the type makes that misuse impossible to express rather than merely documenting against it.
