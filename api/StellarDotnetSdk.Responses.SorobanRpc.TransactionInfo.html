ResultValue

(optional) The return value of the Soroban contract invocation, extracted from the transaction metadata. Both TransactionMetaV3 (Protocol 20-22) and TransactionMetaV4 (Protocol 23+) are supported. A void-returning invocation recorded on a V3 meta yields a non-null SCVoid, because V3's return value is a mandatory XDR field, so test for SCVoid rather than relying on ResultValue != null to tell whether the invocation produced a value. Only present for successful transactions that carry Soroban metadata. Returns null — rather than throwing — when ResultMetaXdr is missing or empty, is not valid base-64, is malformed or truncated, carries an unknown union discriminant, is a metadata version that predates Soroban, holds no return value, or holds a return value this SDK rejects as unrepresentable. A failure that instead signals a gap in this SDK — an SCVal type the mapping does not know — still throws, because that is a defect here rather than bad input; no payload can currently provoke that, since the generated decoder rejects an unknown SCValType first, so treat it as a standing guarantee rather than a case to handle. Unlike TransactionMeta, this property reads the return value straight off the decoded XDR, so it still reports the value when some unrelated part of the metadata cannot be mapped to an SDK type.

public SCVal? ResultValue { get; }

TransactionInfo.TransactionStatus

Remarks

Stellar RPC tags this field json:"status" with no omitempty, so it is always present; JsonRequiredAttribute makes that enforceable. An enum is a value type, so without it a response carrying no status silently yielded the zero member, NOT_FOUND.

TransactionMeta

Holds the transaction metadata. Returns null when ResultMetaXdr is missing or empty, cannot be decoded, is a metadata version this SDK does not model (only v3 and v4 are), or contains any structure that cannot be mapped to an SDK type. This is all-or-nothing: use ResultValue when you only need the Soroban return value, as it does not depend on the rest of the metadata converting successfully. A failure that says nothing about the payload — an OutOfMemoryException, or a defect in this SDK surfacing as a NullReferenceException — propagates rather than being reported here as absent metadata.

public TransactionMeta? TransactionMeta { get; }
