Namespace StellarDotnetSdk.Sep.Sep0007.Exceptions

Classes

InvalidOriginDomainException

Thrown when the origin_domain parameter is not a fully qualified domain name.

InvalidSep7SignatureException

Thrown when the URI's signature does not verify against the origin domain's URI_REQUEST_SIGNING_KEY. SEP-7 requires wallets to alert the user in that case.

InvalidSep7UriException

Thrown when a SEP-7 URI is structurally invalid: wrong scheme, unsupported operation, a missing or malformed parameter, a parameter that does not belong to the operation, or an invalid replace or chain value. Message carries the reason.

InvalidUriRequestSigningKeyException

Thrown when the origin domain's stellar.toml declares a URI_REQUEST_SIGNING_KEY that is not a valid Stellar account id (G...).

MissingOriginDomainException

Thrown when a request signature is created or verified for a URI that has no origin_domain parameter. Without it there is no stellar.toml to take the URI_REQUEST_SIGNING_KEY from.

MissingSignatureException

Thrown when a URI carries an origin_domain but no signature. SEP-7 treats such a request as invalid: the wallet must not display the domain and the user should not sign it.

NoUriRequestSigningKeyFoundException

Thrown when the origin domain's stellar.toml does not declare a URI_REQUEST_SIGNING_KEY.

OriginDomainStellarTomlException

Thrown when the stellar.toml of the origin_domain cannot be fetched or parsed. SEP-7 treats the request as invalid in that case.

Sep7Exception

Base exception for all SEP-7 (URI Scheme to facilitate delegated signing) errors.

UriRequestSigningKeyChangedException

Thrown when the origin domain's current URI_REQUEST_SIGNING_KEY differs from the key the wallet pinned for that domain earlier. SEP-7 requires wallets to alert the user when the key changes, because it may mean the domain was compromised. The signature itself is not checked when this is thrown.
