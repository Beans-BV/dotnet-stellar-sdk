The contract event types a GetEventsRequest.EventFilter can select. Values are combinable: EventFilterType.System | EventFilterType.Contract matches both.

[Flags]
[JsonConverter(typeof(EventFilterTypeJsonConverter))]
public enum EventFilterType

Fields

Contract = 2

Events emitted by contract code. Wire value contract.

None = 0

No type filter. Serializes to the empty string, which Stellar RPC treats exactly like omitting the field: events of every type are returned. Prefer leaving Type null to express this.

System = 1

Events emitted by the host itself rather than by contract code. Wire value system.

Remarks

Stellar RPC transports this as a single string holding a comma-separated set — "contract", "system,contract" — and validates every member against the literals system and contract. The comparison is case-sensitive and the separator is a bare comma: RPC rejects "system, contract" exactly as it rejects a typo. The wire spelling is therefore produced by EventFilterTypeJsonConverter rather than by the built-in enum converter, which would write the ", " that Enum.ToString() uses for a flags combination.

That converter is attached in three places, because System.Text.Json resolves converters in a fixed order — a JsonConverterAttribute on the property, then the options' Converters collection (first match wins), then a JsonConverterAttribute on the type. The attribute on this type alone is the weakest of the three and is outranked by the JsonStringEnumConverter that JsonOptions.DefaultOptions registers for every enum, so Type carries a property-level attribute (which nothing can override), JsonOptions.DefaultOptions registers the converter ahead of JsonStringEnumConverter, and the type-level attribute below covers a bare JsonSerializerOptions that registers neither.

diagnostic is deliberately absent. It was a legal filter value up to Stellar RPC v22.1.5, but Protocol 23 removed diagnostic events from the getEvents stream and RPC v23.0.0 onwards answers filter N invalid: filter type invalid: if set, type must be either 'system' or 'contract' for it, where N is the 1-based index of the offending filter. Every RPC release this SDK supports rejects it, so it is not offered.
