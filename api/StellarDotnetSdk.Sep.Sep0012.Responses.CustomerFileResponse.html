ExpiresAt

Gets the time at which the server discards the file if no PUT /customer request references it, or null when the server did not say. SEP-0012 sends it as a UTC ISO 8601 string; a value without a zone designator is read as UTC, never in the local time zone. More than seven fractional-second digits are rounded to the nearest tick, and a value outside the ISO 8601 grammar, such as a fraction separator without digits, fails the parse.

[JsonPropertyName("expires_at")]
[JsonConverter(typeof(UtcDateTimeOffsetJsonConverter))]
