MaxRepresentableDelay

Longest delay this parser reports; longer values are clamped to it. Chosen as the maximum delay Delay(TimeSpan) accepts (uint.MaxValue - 1 milliseconds, about 49.7 days), so a parsed value can always be awaited directly. A server demanding a longer wait is telling the client to come back another day, not to actually hold a timer.

Parse(object?)

Parses an arbitrary value (a string in delay-seconds or HTTP-date form, int, long, TimeSpan, DateTime, DateTimeOffset, or RetryConditionHeaderValue) into a positive TimeSpan, or null if unparseable, missing, or non-positive. Delays longer than MaxRepresentableDelay are clamped to it. Date strings are accepted in any RFC 7231 HTTP-date form (RFC 1123, RFC 850, or asctime) or ISO 8601 with a time part.
