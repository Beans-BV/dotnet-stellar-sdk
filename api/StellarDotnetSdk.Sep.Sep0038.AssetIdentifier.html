Remarks

Two schemes are defined. stellar identifies a Stellar asset in the SEP-11 format — native for lumens, otherwise CODE:ISSUER, for example stellar:USDC:GA5ZSEJYB37JRC5AVCIA5MOP4RHTM335X2KGX3IHOJAPP5RE34K4KZVN. iso4217 identifies a fiat currency by its three-letter ISO 4217 code, for example iso4217:USD.

SEP-38 request types take assets as strings so any value an anchor lists can be passed through. This type builds and validates those strings; it converts implicitly to string, so it can be assigned to a request property directly: 

var request = new PriceRequest
{
    Context = QuoteContext.Sep6,
    SellAsset = AssetIdentifier.Iso4217("BRL"),
    BuyAsset = AssetIdentifier.FromAsset(usdc),
    SellAmount = 500m,
};
