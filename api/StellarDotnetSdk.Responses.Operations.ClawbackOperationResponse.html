Class ClawbackOperationResponse

Namespace
StellarDotnetSdk.Responses.Operations
Assembly
StellarDotnetSdk.dll

Represents a clawback operation response. Claws back (burns) a specified amount of an asset from an account. This operation can only be performed by the asset issuer on assets that have the clawback-enabled flag set. The clawed back amount is permanently removed from circulation.
