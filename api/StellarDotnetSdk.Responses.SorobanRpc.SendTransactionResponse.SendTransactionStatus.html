DUPLICATE = 1

The transaction is a duplicate of an already submitted transaction.

ERROR = 3

The transaction was rejected due to an error.

PENDING = 0

The transaction has been accepted and is pending inclusion in a ledger.

TRY_AGAIN_LATER = 2

The server is busy; the client should retry the submission later.

Remarks

The type-level JsonConverterAttribute is the third and weakest of the three places the strict converter is attached, and it covers the case the other two miss: the enum travelling on its own — a caller's own DTO field, a persisted status column, a queue message — under a JsonSerializerOptions that registers no converter for it. Without it the built-in enum handling maps a bare integer by ordinal, and ordinal 0 here is PENDING. See EventFilterType for the full three-tier resolution order.
